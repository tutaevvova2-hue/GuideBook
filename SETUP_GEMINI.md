# Работа над книгами через Gemini CLI (бесплатно, Windows)

Gemini CLI — бесплатный помощник в командной строке. Он сам читает файлы репозитория, пишет главы и запускает проверку, поэтому данные переносить не нужно. Правила он берёт из файла `GEMINI.md` в корне репозитория автоматически.

Бесплатно, со входом через обычный аккаунт Google. Суточный лимит большой, но не бесконечный. Когда основная модель (Pro) исчерпана, CLI сам переходит на более слабую (Flash). Если качество упало — продолжи на следующий день.

## Один раз: установка
Поставь четыре программы (везде «Далее → Далее»):
1. **Node.js LTS**: https://nodejs.org
2. **Python 3**: https://www.python.org/downloads/ — при установке отметь галочку **«Add python.exe to PATH»**.
3. **Java (JDK 17 или 21)**: https://adoptium.net
4. **Git**: https://git-scm.com/download/win

Открой **PowerShell** (Пуск → PowerShell) и выполни:
```
npm install -g @google/gemini-cli
```

## Один раз: получить проект
Положи присланный `GuideBook.bundle`, например, в `C:\Books\`. Затем в PowerShell:
```
cd C:\Books
git clone GuideBook.bundle GuideBook
cd GuideBook
git checkout claude/patchouli-minecraft-addon-gcoh36
python build.py --check
```
В конце должно быть `OK`.

## Каждый раз: работа
```
cd C:\Books\GuideBook
gemini
```
При первом запуске выбери **Login with Google** и войди в браузере.

Потом пиши задания обычным текстом, например:
> Прочитай GEMINI.md. Напиши главу 3 «Снаряжение верхнего мира» по PLAN.md и HANDOFF.md, проверь сборкой и сделай коммит.

Когда CLI спрашивает разрешение изменить файл или запустить команду, отвечай «Yes» (или «Always allow»).

Готовый мод появляется в `C:\Books\GuideBook\dist\Tomes-1.12.2-*.jar` — копируй его в папку `mods` сборки.

## Советы
- Проси по одной главе за раз: так меньше ошибок и расход лимита.
- После главы проверяй книгу в игре. Если что-то не так — опиши проблему CLI или пришли скриншот (его можно перетащить в окно терминала).
- Команда `/clear` очищает переписку, если помощник запутался. Правила из GEMINI.md он перечитает сам.
- Сохранить работу на GitHub: подключи репозиторий один раз (`git remote set-url origin https://github.com/tutaevvova2-hue/GuideBook`), потом `git push`.
