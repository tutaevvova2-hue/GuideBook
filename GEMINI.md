# Инструкция для ИИ-помощника (Gemini CLI и другие)

Ты помогаешь писать книги-справочники для сборки Minecraft 1.12.2. Книги живут в моде Tomes, текст — на русском.

## Сначала прочитай
- `REQUIREMENTS.md` — все правила (П-1…П-39). Главное: полное погружение (никаких слов «мод», «сборка», «версия», «конфиг» и названий модов), обращение на «ты», названия предметов — как в игре.
- `books/FORMAT.md` — разметка статей.
- `books/divine/HANDOFF.md` — порядок работы над книгой DivineRPG и проверенные факты.
- `books/divine/PLAN.md` — план глав.
- Образец готовой главы: `books/divine/01_ores.txt`.

## Откуда брать данные (только отсюда, не выдумывать)
- `books/divine/sources/stats.md` — урон, прочность, защита.
- `books/divine/sources/mobs.json` — здоровье, урон, выпадение существ.
- `books/divine/sources/ru_guide.wiki` — порядок прохождения и советы (цифры в нём сверяй со stats.md и mobs.json).
- `tools/data/mod_divinerpg.json` — русские названия (`items`) и рецепты (`recipes`). Рецепт в книге подставляется сам: `== craft divinerpg:<id>`.

Если нужного факта нет в этих файлах — не придумывай. Напиши в конце ответа, чего не хватило.

## Как работать над главой
1. Напиши файл `books/divine/NN_<раздел>.txt`, где `NN` — следующий номер по порядку.
2. Для новых групп открытия допиши `books/divine/unlocks.txt`.
3. Запусти `python build.py --check`. Если есть раздел «Ошибки» — исправь и запусти снова, пока не будет `OK`. Предупреждения «группа … ничего не открывает» допустимы.
4. Запусти `python build.py`: готовый мод появится в `dist/`.
5. Сделай коммит: `git add -A` и `git commit -m "Книга DivineRPG: глава …"`.

## Нельзя
- Менять `tools/`, `vendor/`, `build.py` и `books/industrial/`, если об этом прямо не попросили.
- Ставить ссылку `[[id|текст]]` на статью, которой ещё нет.
- Писать цифры, которых нет в файлах данных.
