# Разметка книг Tomes

Каждая книга — папка `books/<книга>/`:

- `book.json` — настройки книги Patchouli (название, текстуры, цвета, шкала прогресса);
- `unlocks.txt` — группы предметов, открывающие статьи;
- `*.txt` — разделы и статьи (обычно файл на раздел, `00_start.txt`, `01_power.txt`…).

Компилятор `tools/tome.py` превращает всё это в JSON для Patchouli, скрытые достижения и шаблоны страниц.
Запуск — через `python3 build.py` (сборка jar) или `python3 build.py --check` (только проверка).

## Раздел

```
@category power
name: Электричество
description: Короткое описание под названием раздела.
icon: te#batbox
sort: 1
```

## Статья

```
@entry cables
name: Провода
icon: ic2:cable#type:copper,insulation:1
sort: 1
unlock: wiring            группа из unlocks.txt; без строки статья открыта сразу
next: auto                «Что дальше»: auto (по умолчанию), none или список групп через запятую
provides: te#mfe          предметы, которые статья «даёт» кроме рецептов на её страницах (для next: auto)
priority: yes             выделить статью в списке
read_by_default: yes      не помечать статью как новую
```

Название статьи — не шире 104 пикселей (компилятор предупредит).

## Страницы

Страница начинается строкой `== <тип> …`, всё до следующей `==` — её содержимое.
Название страницы пишется после `|`: `== text | Где искать`.

| Страница | Что это |
|---|---|
| `== text` | текст |
| `== spotlight <предмет>` | предмет крупно и текст под ним |
| `== craft <предмет> [номер]` | рецепт верстака из файлов IC2; текст — подпись |
| `== grid <результат>` | рецепт вручную: три строки по три предмета (`_` — пусто), дальше подпись; `== grid <результат> shapeless` — без формы |
| `== machine <машина>` | рецепты машины: строки `вход -> выход [выход2 …]` или `вход1 + вход2 + вход3 -> выход`; остальное — подпись. Рецепты сверяются с файлами IC2, длинные списки сами переносятся на следующую страницу |
| `== image файл.png` | готовая картинка из `tomes/resources/assets/tomes/textures/gui/<книга>/` |
| `== shot файл.png` | место под скриншот: описание, что снять, строка `--`, подпись. Пока файла нет, страница пропускается и попадает в `SCREENSHOTS.md` |
| `== multiblock`, `== entity`, `== relations` | объёмная постройка, существо, список связанных статей |
| `== raw {json}` | страница Patchouli как есть |

Текст: пустая строка — новый абзац, строка с `- ` — пункт списка.
Если текст не помещается, компилятор переносит его на следующую страницу по абзацам и пунктам.

## Оформление текста

| Разметка | Вид | Для чего |
|---|---|---|
| `**Предмет**` | синий | то, о чём статья |
| `*Предмет*` | фиолетовый | другие предметы и материалы |
| `~понятие~` | зелёный | понятия, режимы, улучшения |
| `!!осторожно!!` | красный | опасность |
| `[[статья\|текст]]` | ссылка | на другую статью; ссылка на закрытую статью не открывается |
| `$(k:Mode Switch Key)` | клавиша | название клавиши из настроек управления |

## Предметы

- `te#macerator` — блок-машина IC2 по имени;
- `ic2:crafting#circuit`, `ic2:cable#type:copper,insulation:1` — предметы IC2 с вариантом;
- `minecraft:iron_ingot`, `minecraft:dye:4`, `gravisuite:crafting:1` — по имени и мете;
- `ore:plateIron` — словарь руд (показываются все подходящие предметы по очереди);
- `ic2:fluid_cell#water`, `fluid:water` — капсула с жидкостью и сама жидкость;
- `a|b` — любой из вариантов, `*3` в конце — количество.

Названия берутся из официального русского перевода: IC2 — из `tools/data/ic2.json`,
остальное — из `tools/data/items_extra.json` (туда же дописываются новые предметы).

## Группы открытия (`unlocks.txt`)

```
@group wiring
- ore:itemRubber
- ic2:cable#type:copper,insulation:0 | Медный провод
```

Статья с `unlock: wiring` откроется, когда у игрока в инвентаре окажется любой предмет группы.
Необязательное имя после `|` — как предмет назвать на странице «Что дальше».
