@entry metals
name: Металлы и пластины
icon: ic2:plate#copper
sort: 0
unlock: metal

== spotlight ic2:ingot#copper
Инженер работает не столько со слитками, сколько с тем, что из них сделано:
- *пластины* — основа почти всех рецептов;
- *оболочки* — тонкие листы для аккумуляторов и деталей;
- *плотные пластины* — для прочных вещей;
- *провода* — из пластин.

== text | Слитки
- **Медь** и *олово* — первые металлы, из руды в печи.
- *Бронза* — сплав меди и олова, см. [[bronze|Бронза]].
- *Свинец* и *серебро* — из своих руд и побочных продуктов обогащения.
- *Сталь* — из железа в доменной печи.
- *Очищенный уран* — топливо реактора.

== text | Пластины
Слиток превращается в *пластину*:
- вручную — [[hand_tools|Кузнечным молотом]] на верстаке;
- без износа инструмента — [[metal_former|Металлоформовочной машиной]] в режиме проката.

Пластины бывают из железа, меди, олова, бронзы, золота, свинца, стали, а также из лазурита и обсидиана — их прессуют в [[compressor|Сжимателе]] из пыли.

== craft ic2:plate#copper

== text | Оболочки
Пластина под молотом становится двумя *оболочками*. Металлоформовочная машина делает то же самое.
- *Оловянная оболочка* — корпус аккумулятора и консервных банок.
- *Железная оболочка* — силовые агрегаты.
- *Бронзовая оболочка* — улучшенный аккумулятор.
- Медная, золотая, свинцовая и стальная — для особых деталей.

== craft ic2:casing#tin

== text | Плотные пластины
Девять пластин одного металла [[compressor|Сжиматель]] прессует в одну *плотную пластину*. Она идёт в броню, реакторные детали и прочные корпуса.

Дробитель перемалывает плотную пластину обратно в девять кучек пыли, так что ошибка не страшна.

== machine te#compressor
ore:plateIron*9 -> ic2:plate#dense_iron
ore:plateCopper*9 -> ic2:plate#dense_copper
ore:plateLead*9 -> ic2:plate#dense_lead

== text | Блоки металлов
Девять слитков на верстаке складываются в *блок*, а блок обратно разбирается на девять слитков. Блоки удобны для хранения.

Из бронзового, железного и стального блоков Металлоформовочная машина вытягивает стержни для роторов и турбин.

== craft ic2:resource#copper_block

== text | Мелочи
- Железную оболочку Металлоформовочная машина режет в *монету*. Из восьми монет на верстаке снова выходят два железных слитка.
- Из железной пластины вытягивается пустой *топливный стержень* для реактора.
- Из железной оболочки — секция *железного забора*.

@entry bronze
name: Бронза
icon: ic2:ingot#bronze
sort: 1
unlock: bronze

== spotlight ic2:ingot#bronze
**Бронза** — первый сплав инженера: из неё делают [[wrench|гаечный ключ]], инструменты, броню, МЭСН и детали кинетических генераторов.

Бронзу не сплавить из слитков. Её смешивают из ~пыли~ или ~измельчённой руды~, поэтому бронза появляется только после [[macerator|Дробителя]].

== craft ic2:dust#bronze 2
Три части меди и одна часть олова дают четыре бронзовой пыли. Подходит и пыль, и измельчённая, и очищенная руда.

== text | Как получить
- Раздроби медную и оловянную руду в [[macerator|Дробителе]].
- Смешай на верстаке три меди и одно олово.
- Переплавь *Бронзовую пыль* в печи в слитки.

Если остались лишние слитки меди и олова, их тоже можно раздробить в пыль.

== machine minecraft:furnace
ic2:dust#bronze -> ic2:ingot#bronze
Пыль плавится в любой печи.

== text | Бронзовые инструменты
Кирка, топор, лопата, мотыга и меч из бронзы ничем не уступают железным: та же скорость, тот же урон, добывают ту же руду. Зато служат в полтора раза дольше: 350 ударов против 250.

Бронзовая броня защищает ровно как железная. Инструменты и броню чинят на наковальне бронзовыми слитками.

== spotlight ic2:crafting#circuit
**Электросхема** — мозг почти каждой машины. Её собирают из изолированных медных проводов, редстоуна и железной пластины.

Схем понадобится много: на генератор, дробитель, электропечь и каждую следующую машину.

== craft ic2:crafting#circuit

== craft ic2:crafting#circuit 2
Второй вариант: те же материалы, другая раскладка.

== spotlight ic2:crafting#advanced_circuit
*Улучшенная электросхема* — для продвинутых машин, лазуротроновых кристаллов, МФСУ и мощных инструментов.

К обычной схеме добавляются редстоун, лазурит и светокаменная пыль.

== craft ic2:crafting#advanced_circuit

== text | Примечания
- Светокаменную пыль даёт светокамень из Нижнего мира: в [[macerator|Дробителе]] блок светокамня распадается на четыре пыли.
- Храни запас схем: они нужны почти в каждом рецепте машины.

== spotlight ic2:resource#machine
**Базовый корпус машины** — основа почти всех машин. Восемь железных пластин кольцом.

Это же он выпадает, если сломать машину без [[wrench|ключа]].

== craft ic2:resource#machine

== spotlight ic2:resource#advanced_machine
*Улучшенный корпус машины* нужен продвинутым машинам: индукционной печи, телепорту, терраформеру, машинам материи, МФСУ.

Для него нужны *стальные пластины*, [[alloys|композит и углепластик]].

== craft ic2:resource#advanced_machine

== text | Примечания
- Корпус — это блок: его можно поставить в мир, например как прочную стену.
- Сталь для улучшенного корпуса выплавляется в доменной печи из железа.

== spotlight ic2:crafting#alloy
**Композит** — прочный лист из трёх металлов. Идёт на улучшенный корпус, композитную броню, укреплённое стекло и камень.

- четыре пыли — *Углеволокно*;
- два волокна — *Углеткань*;
- углеткань в Сжимателе — *Углепластик*.

== spotlight ic2:crafting#coal_ball
Уголь — не только топливо. Если долго прессовать его, выйдет **алмаз**.

Цепочка:
- уголь в [[macerator|Дробителе]] — *Угольная пыль*;
- восемь пыли и кремень — *Угольный шарик*;
- шарик в Сжимателе — *Сжатый угольный шарик*;
- восемь сжатых шариков и обсидиан — *Угольная глыба*;
- глыба в Сжимателе — *Алмаз*.

== craft ic2:crafting#coal_ball

== machine te#compressor
ic2:crafting#coal_ball -> ic2:crafting#coal_block

== craft ic2:crafting#coal_chunk

== machine te#compressor
ic2:crafting#coal_chunk -> minecraft:diamond
Угольная глыба в Сжимателе становится алмазом.

== text | Стоит ли
На один алмаз уходит 64 угля, обсидиан и восемь кремней. Это дорого, но зато алмаз можно получить, не спускаясь в шахту.

Угольная пыль нужна и сама по себе: для углеволокна, одноразовых батареек и гидратированного угля.

@entry dusts
name: Пыль
icon: ic2:dust#copper
sort: 7
unlock: workshop

== spotlight ic2:dust#copper
[[macerator|Дробитель]] перемалывает слитки, пластины и многое другое в **пыль**. Из пыли снова получаются слитки в печи, а ещё из неё смешивают сплавы.

== text | Кучки пыли
Мелкие остатки обогащения — *небольшие кучки* пыли: медной, оловянной, серебряной, свинцовой, серной, лазуритовой и других.

Девять кучек складываются на верстаке в одну целую пыль. Сжиматель делает то же самое.

== craft ic2:dust#bronze 1
Так из девяти кучек выходит одна пыль. Для других металлов рецепт тот же.

== text | Полезная пыль
- *Угольная* — углеволокно и одноразовые батарейки.
- *Алмазная* — энергетическая пыль.
- *Лазуритовая* — лазуритовая пластина, лазуротроновый кристалл.
- *Обсидиановая* — обсидиановая пластина.
- *Серная* — улучшенный аккумулятор и порох.
- *Каменная* — побочный продукт промывки, для строительной пены.

== machine te#macerator
minecraft:coal -> ic2:dust#coal
minecraft:obsidian -> ic2:dust#obsidian
minecraft:lapis_block -> ic2:dust#lapis*9
Примеры: уголь, обсидиан и лазуритовый блок.
